    how does it work?

    the score (0-100) adds up points for length, for using different kinds of characters (a-z, A-Z, 0-9, symbols) and for not repeating the same characters. points get taken off for really common passwords (even with swaps like a to @), keyboard patterns like qwerty and number runs like 1234. *crack time is a rough guess that assumes 10 billion guesses a second, real attackers are smarter than that so don't treat it as exact.

    runs fully in your browser, nothing is saved or sent anywhere.
